# Atlan Studio — downloads

**Português (Brasil)** · [English](#english) · [Español](#español)

Aqui ficam os instaladores do **Atlan Studio** para Windows 10 e 11 (64 bits): o visualizador e catálogo de bordados
(antes PES Viewer) e o gerador de bordados (antes PES Generator), num só programa. Baixe o `.exe` em
**[Releases](../../releases)** e confira o arquivo `.sha256` se quiser verificar o download. O programa procura as
atualizações aqui.

A primeira versão ainda está sendo preparada.
